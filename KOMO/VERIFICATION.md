本轮核验日期为 2026-10-17。当前改动覆盖桌面登录恢复、显式注册入口、缓存错误处理、新手引导、每日推荐、Python 模型调用并发，以及部署后的健康检查。源码提交不等于服务器已更新；只有之后部署相应的前后端和 AI 服务，线上才会使用这些修复。

Java 在 `KOMO/backend` 运行 `mvn compile test`。本轮 101 项单元测试通过，新增场景包括刷新接口区分凭证过期与数据库异常、账号不存在时让旧会话失效、当天已处理的推荐不重复自动生成，以及模型失败时保留旧推荐。测试验证了推荐的数据库写入同处短事务，模型调用位于事务外。本轮没有运行需要真实数据库或 Elasticsearch 的集成测试。

前端在 `KOMO/frontend/packages/web` 运行 `npm test`，本轮 50 项测试通过。覆盖异步凭证加载、自动续期、并发与迟到响应、登录和退出的持久化、注册响应和密码提示、缓存拒绝掩盖权限错误、新手进度及草稿确认路由。`npx next build` 的Web生产构建通过；桌面在 `packages/desktop` 运行 `npm run build`，静态页面、Windows可执行文件和NSIS安装包均构建成功。构建前须彻底退出旧客户端，避免常驻进程占用exe。

Python 在 `KOMO/ai-service` 运行 `python -m unittest discover -s tests`，本轮 13 项测试通过。模型接口使用异步替身，不读取项目密钥、不请求真实模型。并发测试让提取、去重或推荐停留在等待模型的状态，再确认聊天能输出首段内容；这验证了事件循环可继续运行，不代表测得了真实 DeepSeek 延迟或吞吐量。
